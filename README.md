# SISTEMA-INTEGRADO-DE-INFORMA-O-DA-SAUDE
Sistema Integrado de Informação da Saúde da Província do Uíge (SIIS-UÍGE), desenvolvido em Python, com interface gráfica e arquitectura cliente-servidor, destinado à integração de unidades de saúde, partilha de dados e consulta do histórico clínico dos pacientes.
